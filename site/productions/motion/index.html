How it works


A scenes file says what happens (motion.scene/v1): a list of scenes, each a type and its vars. motion.js draws each type from those variables only, as a pure function of time, so scrubbing and stills always agree. It runs on any page: <div data-motion="file.json"></div>. With reduced motion set, you get each scene as a still, with Back and Next.


Read the design in DESIGN.md, or see the brief made from c.maestro's feeds.
